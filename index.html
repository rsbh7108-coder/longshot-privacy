LongShot Privacy Policy

Last updated: September 24, 2026

LongShot’s single purpose is to let users capture a user-selected scrollable region of the active webpage and export it as a long screenshot or AI-ready image segments.

1. Data LongShot handles

When the user explicitly starts a capture, LongShot temporarily accesses content visible in the active browser tab in order to create the requested screenshot. Depending on the webpage selected by the user, this content may include webpage text, images, reviews, user-generated content, usernames, or personal communications.

2. How the data is used

The accessed webpage content is used only to provide the screenshot functionality requested by the user, including region selection, scrolling, rendering, stitching, segmentation, and local download of the resulting files.

3. Data transmission and storage

LongShot does not transmit captured webpage content, screenshots, browsing history, account credentials, or generated files to the developer or to a LongShot remote server. Screenshot processing is performed locally in the user’s browser. Generated files are downloaded directly to the user’s device.

4. Analytics, advertising, and sale of data

LongShot does not use captured webpage content for advertising, profiling, personalized advertising, credit decisions, lending decisions, or data brokerage. LongShot does not sell user data. This version does not include third-party advertising or analytics SDKs.

5. Chrome extension permissions

  • activeTab: provides temporary access to the currently active tab after the user explicitly invokes LongShot.
  • scripting: allows LongShot to inject the region-selection UI and scrolling/capture logic into the active tab.
  • downloads: allows LongShot to save generated PNG and ZIP files to the user’s device.

6. Limited Use

LongShot’s use of information accessed through Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements. Data is used only to provide or improve the user-facing screenshot functionality described above and is not transferred for advertising or unrelated purposes.

7. Data retention

LongShot does not maintain a developer-operated database of captured webpage content or generated screenshots. Any files downloaded by the user remain under the user’s control on their device.

8. Changes to this policy

If LongShot’s data practices materially change, this privacy policy and the Chrome Web Store privacy disclosures will be updated before or together with the relevant product update.

LongShot 隱私權政策

最後更新：2026 年 9 月 24 日

LongShot 的單一用途，是讓使用者截取目前分頁中自行框選的可捲動區域，並輸出為長截圖或適合 AI 分析的分段圖片。

1. LongShot 會處理哪些資料

只有在使用者主動啟動截圖後，LongShot 才會暫時存取目前作用中分頁中顯示的內容，以完成使用者要求的截圖。 依使用者所選擇的網頁不同，這些內容可能包含網頁文字、圖片、評論、使用者產生內容、使用者名稱或個人通訊內容。

2. 資料使用方式

LongShot 僅將目前分頁內容用於使用者主動要求的長截圖功能，包括框選區域、捲動、渲染、拼接、分段及將結果下載至本機裝置。

3. 資料傳輸與儲存

LongShot 不會將截取的網頁內容、截圖、瀏覽紀錄、帳號憑證或產生的檔案傳送給開發者或 LongShot 遠端伺服器。 截圖處理皆在使用者的瀏覽器本機完成，產生的檔案會直接下載到使用者裝置。

4. 分析、廣告與資料販售

LongShot 不會將截取的網頁內容用於廣告、使用者剖析、個人化廣告、信用判斷、貸款決策或資料仲介。 LongShot 不會販售使用者資料。本版本也不包含第三方廣告或分析 SDK。

5. Chrome 擴充功能權限

  • activeTab：只有在使用者主動啟動 LongShot 後，暫時存取目前作用中的分頁。
  • scripting：用於在目前分頁注入框選介面，以及執行捲動與截圖流程所需的套件內建程式碼。
  • downloads：用於將產生的 PNG 與 ZIP 檔案儲存到使用者自己的裝置。

6. Limited Use

LongShot 對透過 Chrome API 所取得資訊的使用，遵循 Chrome Web Store User Data Policy，包括 Limited Use 要求。 資料只會用於提供或改善上述使用者主動要求的截圖功能，不會轉移至廣告用途或其他無關用途。

7. 資料保留

LongShot 不會建立由開發者營運的資料庫來保存使用者截取的網頁內容或產生的截圖。 使用者下載的檔案會留存在使用者自己的裝置，並由使用者自行管理。

8. 政策變更

如果 LongShot 的資料處理方式有重大變更，將在相關產品更新之前或同時更新本隱私權政策與 Chrome Web Store 的隱私權揭露內容。
